## 📌 Project Overview

This project is a **personal portfolio website** built as part of the assignment.  
The goal of this project is to create a **fully responsive portfolio website** using custom design without using any pre-built templates.

The website showcases personal information, skills, services, work experience, and contact details.

---

## 🚀 Features

- Responsive design for **mobile, tablet, and desktop**
- Modern **Hero Section**
- Skills showcase
- Services section
- Work experience timeline
- Contact form
- Clean footer
- Mobile navigation menu
- Scroll reveal animations using JavaScript

---

## 🛠 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Responsive Design

---

## 📱 Responsive Design

The website is fully responsive and optimized for:

- Mobile devices
- Tablets
- Laptops
- Large desktop screens

Tailwind CSS breakpoints are used to maintain proper layout across all screen sizes.

---

## 📂 Website Sections

The portfolio website includes the following sections:

- Header
- Hero Section
- Skills
- Services
- Work Experience
- Contact
- Footer

---

## 💡 Purpose of the Project

The purpose of this assignment is to demonstrate:

- Frontend development skills
- Responsive web design
- Clean UI layout
- JavaScript interaction
- Unique design thinking
